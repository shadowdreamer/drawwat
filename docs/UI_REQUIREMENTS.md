# DrawWat 界面实现与待办

核对日期：2026-10-23。基于 Vue 页面、组件和样式的静态审核；未做浏览器视觉、设备或无障碍验收。功能/API 见 [PRD](PRD.md)，缺陷见 [审核记录](README.md)。

## 样式与图标

`unocss.config.ts` 使用 presetWind4、presetAttributify、presetDaisy、presetIcons，以及 directives/variantGroup transformers。Vite 配有图标组件解析及组件自动导入。现有页面主要用 `i-lucide-*`，package.json 提供 `@iconify-json/lucide`，不应按旧文档把 MDI 写作当前图标系统。

通用 UI 直接使用 DaisyUI 的 btn、card、input、textarea、alert、badge、modal、loading 等类，没有单独的通用 Button/Input/Card 组件库。

`src/styles/main.css` 使用雾白、淡紫、蜜桃和薄荷色弥散光背景，定义亮暗两套颜色变量、统一按钮/卡片/表单和可见键盘焦点。字体采用 Inter、苹方、微软雅黑及系统 sans-serif 回退，不依赖外部字体请求；支持减少动态效果偏好和页面缩放。

## 创建与画板的实际边界

答案和提示输入框 maxlength=500；canSubmit 只看 trim 后答案是否非空，提交时再检查画板导出是否为空。前端不提供独立文件选择上传控件；创建接口接受 multipart 图片不代表 UI 有单独上传表单。

画板使用 localStorage key `drawwat-excalidraw-draft-v1` 保存元素、图片文件、白色背景和视口，变更后延迟 500ms 保存，离开页面时立即保存；恢复失败或保存空间不足时提示。原 tldraw 草稿格式不兼容，不自动迁移。没有服务端草稿或实时协作功能。导出全部未删除元素为 WebP，保留背景、padding=10、质量 0.9，最长边超过 1280 时缩放，固定按白底亮色模式导出。画板不跟随网站主题，恢复旧草稿时也统一为白底，并隐藏画板的主题及背景色切换入口。

创建页采用单实例响应式布局，桌面左画板右表单，移动端上下排列；导出和清空均通过当前组件实例调用，不依赖全局元素 ID。实际设备操作仍需验收。

## 主题

主题类型仅 light/dark。`App.vue` 挂载后调用 initTheme，导航按钮调用 toggleTheme，并通过 html `data-theme` 应用。初始化意图为优先已保存主题，否则跟随系统偏好。

主题统一使用 `drawwat-theme` 保存 light/dark 字符串，兼容旧 Pinia JSON 对象格式；浏览器验证切换和刷新恢复通过。存储不可用时仍可切换。没有监听系统偏好后续变化的实现。
